This is the last V0 tag in the [captured prerelease archive](../releases/README.md); the [tag record](../releases/astro-one-v0.1.2-rc.1.md) preserves its release context. <a id="characteristics"></a>
## Format characteristics

These facts describe the selected checkpoint. The generated tables below preserve the exact field types and optionality.

- `SessionHeader.version` and physical `JsonlHeaderLine.version` are declared as `number`. The source writer constant establishes V0; the numeric type alone does not restrict values to 0.
- The logical header requires `isSeeded`. The physical header instead stores optional `seedLength`, with required `delegationDepth` and `type: "session"`.
- `assistant/chunk.data` contains `chunk`, `turn`, and `step`. `assistant/message.data` has no embedded `stream`, and `assistant/attempt` is absent.

The [V0/V1 codec](../../../packages/session/session-format-v0-to-v1/src/codec.ts) owns packed Assistant rows and range-encoded source references. These physical body encodings are not additional roots in this declared-type inventory. The [adjacent migration reference](../../../packages/session/session-format-v0-to-v1/README.md) owns accepted legacy normalizations and refusal rules.

Packed physical rows use `text-chunks`, `reasoning-chunks`, or `tool-call-chunks`, with `seq0`, `time0`, and `data.turn` / `step` / `index` / `dt`. Text and reasoning rows carry `texts`; tool-call rows carry `id`, optional `name`, and `args`. For N members, `dt` has N−1 time gaps, which may be negative. Member k has sequence `seq0 + k` and time `time0` plus the first k gaps. Physical `sourceEventSeqs` may use encoded ranges; the logical schemas below show expanded number arrays.

## Verification and limitations

The [source-only extractor](../../../scripts/persistence-schema.ts) ran with TypeScript 6.0.3. Reconstruction omits redundant `object` intersection members and discards normalization-unreachable type definitions; it preserves existing `any` / `unknown` and does not substitute opaque types for unresolved imports. V0 and V2 root digests match the corresponding complete states reconstructed from the prerelease archive.

Historical surface-event declarations permit optional `surfaceOp`. This is retained evidence of declared types, not permission to omit fields required by a codec or migration validator. Opaque values, external plugin events, packed body encoding, and runtime relationships are outside the type inventory’s coverage.

```sh
pnpm run verify-persistence-formats
```

The check validates every format through the current writer, schema completeness, bilingual declarations, and generated tables using only this checkout. It does not replay historical applications or establish migration safety. See the [format index](README.md) for maintenance rules and the [current catalog](../../persistence-catalog.md) for today’s declarations.
