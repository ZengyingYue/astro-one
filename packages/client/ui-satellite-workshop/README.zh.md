# @astro-one/client-ui-satellite-workshop

[English](README.md) | 中文

## 概述

本包为 Web 客户端的侧栏增加**卫星工坊**入口及其打开的页面。用户选择任务和卫星平台，在三维工作台上用鼠标或键盘把目录中的部件安装到平台上，并随选配变化查看质量、功率、蓄电池、速度增量、指向精度、数传和热控预算。点击一个按钮即可把选配、预算和违反的规则作为新会话的第一条提示词发给大模型，由大模型判断该配置是否合理、是否适用于所选任务。

<a id="use-this-package"></a>
## 使用本包

Web 应用 bundle 通过 `ui-satellite-workshop` 行加载本包；页面无需配置。选配保存在浏览器存储中，首次访问从对地观测参考方案开始。

### 部件目录

目录包含三种平台（50 kg 级、200 kg 级、2 吨级）、六类共 28 个部件（电源、有效载荷、测控数传、姿态控制、推进、热控）和五种任务（近地轨道对地观测、低轨物联网星座、中轨导航、地球静止轨道通信、深空科学探测）。每种平台提供太阳翼铰链、对地面、对天面和迎风面安装位、一个尾部推力板以及舱内安装位；部件只能安装在与其安装类型相同的安装位上。其中四种任务带有通过全部规则的参考方案。

### 鼠标与键盘

| 操作 | 鼠标 | 键盘（画布获得焦点时） |
|---|---|---|
| 旋转视角 | 拖动空白处 | 方向键或 `W` `A` `S` `D` |
| 缩放 | 滚轮 | `+` / `-` |
| 复位视角 | **复位视角** | `R` |
| 拿起部件 | 在部件库中点击 | — |
| 安装手中的部件 | 点击高亮的安装位 | `Q` / `E` 选择安装位，再按 `Enter` |
| 安装到第一个空闲安装位 | 双击部件，或从部件库拖到工作台 | — |
| 移动已装部件 | 拖到另一个同类安装位；目标已占用时两者互换 | — |
| 拆下部件 | 右键点击，或使用已安装列表中的拆卸控件 | 在聚焦的安装位上按 `Delete` |
| 爆炸视图 | **爆炸视图** | `X` |
| 放下手中的部件 | 再次点击该部件 | `Esc` |

手持舱内部件、聚焦舱内安装位或打开爆炸视图时，平台本体变为半透明，以显示舱内安装位。

### 预算与规则检查

每次改动后页面重新计算七项一阶预算：湿重与平台上限、轨道平均发电与负载、蓄电池容量与按 60% 放电深度计算的最长地影需求、由火箭方程得出的速度增量与任务需求、由已装执行机构和星敏感器得出的指向精度与部件最严要求、轨道平均下行能力与载荷数据量、热耗与散热能力。二十条规则报告错误（预算不满足、缺少任务载荷、没有姿态控制、没有链路）和警告（余量偏小、对地载荷未装在对地面、星敏感器装在对地面、只有一侧太阳翼、动量轮无法卸载、磁力矩器处于无可用磁场的轨道）。

### 大模型评估

**交给大模型评估**会在当前显示会话所属的工作区（没有时取第一个工作区）中打开一个空白会话，并在其中提交评估提示词。提示词使用界面语言，依次说明任务、平台、每个已装部件及其安装位和参数、七项预算和规则检查结果，然后要求给出合理性、适用性、风险、具体的部件调整和 0–100 的评分。**复制评估提示词**把同样的文本放入剪贴板。没有工作区时页面提示用户先添加；提示词被拒绝或会话创建失败时显示提示且不发送任何内容。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

`catalog.ts` 保存平台、部件和任务；`assembly.ts` 根据平台尺寸推导安装位，并声明工坊 store，其 actions 是唯一的写入途径。`budgets.ts` 以纯函数计算预算和规则结果，`presentation.ts` 为页面和提示词生成同一套文字，因此模型读到的数值与用户看到的一致。已保存的选配可能引用后来目录中已删除的部件或安装位；`mountsOf` 会略过这些条目。

`bench.ts` 管理一个 three.js 场景：平台、每个安装位的标记，以及由 `models.ts` 程序化生成的已装部件模型。它只绘制所有者传入的视图，不保存选配状态。`Viewport.tsx` 管理画布、动画循环以及指针和按键处理。`LazyViewport.tsx` 仅在页面打开时加载该分块及其中的 three.js；该分块不从入口 bundle 导入任何值。在减少动态效果偏好下，部件和视图不经动画直接就位。WebGL 不可用时页面显示提示，部件库、双击安装和已安装列表仍可使用。

</details>

<a id="model-experience"></a>
## 模型体验

### 评估提示词

#### 模型看到什么

每次评估产生一条用户消息，它与手动输入的消息一样经会话控制器提交并记录在会话日志中。消息是使用界面语言的 Markdown：一段请求，由选配填充的`任务`、`平台`、`已安装部件`、`工程预算`和`规则检查`各节，以及五个编号问题，分别询问合理性、适用性、风险、具体的部件调整和 0–100 的评分。本包不添加工具、系统提示词文本或上下文提供方。

#### Token 影响

有条件：用户发起评估之前不发送任何内容。一条消息包含七行预算、每个已装部件一行（最大的平台上至多 15 行）以及每条违反的规则一行。

#### KV Cache 影响

仅追加：提示词是新会话的第一条用户消息，位于未变化的系统提示词和工具列表之后。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

以下限制说明预算和评估的可信范围。

- **目录数值是同类产品的典型值**，不是具体型号的数据，预算是一阶估算关系。它们未经真实卫星或独立设计工具校验。
- **评估结果是一段对话回答。** 页面不读取模型的回复，因此不显示自己的评分，也不会把建议的调整应用到选配上。
- **只有一个推进安装位，安装位布局固定。** 不能组合多套推进系统或增加安装位，部件在安装位内的朝向固定。
- **三维工作台需要 WebGL。** 降级方式支持选配和预算，但不支持空间装配。

<a id="dev-note"></a>
### 开发备注

<details>
<summary>维护者的工作上下文——点击展开</summary>

在探测运行中的 Web 服务之前，先用 `pnpm --filter @astro-one/client-ui-satellite-workshop bundle` 重新构建。工作台分块不得从 `catalog.ts` 和 `assembly.ts` 导入值；共享的值会让打包器生成模块加载器无法解析的同级分块。

</details>

**运行时不变式：** 不发布伴生入口。槽位注册是由槽位注册表观察的 effect，预算是 store 状态的纯函数，不存在可能与之偏离的第二个观察。
